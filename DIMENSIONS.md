# Dimension reference — Echo GHD Roller Assembly & SM-2.5 Monster Squat Stand 2.0

Compiled 2026-10-26 for Rory's custom GHD design work. Every value is labelled:
**Published** = from Rogue's own pages/guides · **Inference** = derived, verify before use ·
**Missing** = not published anywhere found; needs Rogue or hands-on measurement.
Nothing in this file is fabrication-ready on its own.

## Official CAD files

- Rogue publishes **no CAD/STEP downloads** for either product (searched product pages,
  Rogue support guides, and CAD libraries, 2026-10-26). Spec sheets are the official ceiling.
- The Echo GHD is patented; the filings contain detailed multi-view drawings of the roller
  assembly (perspective, front, top, side) but are **schematic — no numeric dimensions**.

## Community CAD (use as geometry reference only — user-modelled, unverified)

- GrabCAD: "Rogue RM-4 Monster Rack 2.0 EU-version" — a builder's full model of the RM-4
  rack (not the SM-2.5 stand), adapted to EU/M20 bolts. Useful for Monster upright
  proportions; do not trust its dimensions for fabrication.
- Thingiverse/Printables: small accessories modelled against Monster (1 in holes) and
  Monster Lite (5/8 in holes) uprights — phone holders, band pegs, J-cup inserts.
  Interface dimensions in these models are hobbyist-measured.

## Patent filings (design reference — architecture, not dimensions)

- US20150367168 — "Rack-Mounted Glute-Ham Developer and Method for Making the Same"
  (filed/published Dec 2015): FIGS. 5–8 are dedicated roller-assembly views
  (perspective, front elevation, top, side elevation).
- US20160045780A1 — "Glute Ham Developer": describes the pad + roller system coupling
  to an existing upright and Games Box; drawings schematic, some parts distorted for clarity.

## What still gates the custom design

1. Echo roller mounting spec (pin diameter confirmed, plate hole pattern, roller offset) —
   obtainable only from Rogue (follow-up draft Q2, unsent, needs Rory's approval) or by
   measuring a purchased Echo assembly.
2. Rory's own stand: base bolt pattern + the four checklist measurements in
   `GHD_measure_checklist.md` (bolted-down status, clear depth × width, box on hand).
